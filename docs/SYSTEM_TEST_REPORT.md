测试日期：2026-11-14。详细数据见 `SYSTEM_TEST_REPORT.json`，复现脚本为 `scripts/verify_materials_system.py`。

## 范围

- 对用户提供的“科研小助手”资料包 `pdf/` 下全部 39 份 PDF 执行真实 HTTP 上传和后台解析，共 1986 页。

## 结果

- 已有回归测试：127 项通过，28.69 秒；JavaScript 语法和 Python 编译检查通过。
- 真实流程检查：32 项，其中 26 项通过、6 项未通过。
- 全部 39 份 PDF 均写入预期页数，没有解析任务失败或最终 partial 文档。ready 状态仅描述当前解析器的任务判定，不代表满足全部细粒度解析要求。
- 15 页扫描 PDF 使用 RapidOCR 完成全部页面文本写入，约 149.9 秒。
- 541 页教材完成全量写入，约 104.1 秒；最后一页的文本接口及页图接口均可访问。
- 39 个文件节点生成 239 条带原文出处的匹配连边。包含同一论文的不同版本，不能将 39 个节点等同于 39 篇独立论文；连边未全部人工验准。

## 通过的主要流程

1. 首页与状态接口。
2. v7 入库后，改名的 v1 上传得到 409，并提示库中版本较新。
3. 全部材料导入、扫描页 OCR 文本写入、原文页面/PNG 读取。
4. Layer Normalization 参考文献条目抽取、v1/v7 正文差异比较。
5. 图谱生成与边的原文页锚点存在性检查。
6. 折线、柱状、散点、雷达、三维雷达五种图型及输出文件。
7. 非有限数值 CSV 拒绝；专门创建的临时文献副本可修改元信息并删除。
8. arXiv 真实查询、追踪主题配置。
9. 普通原生 PDF 的 GPU/Adam 选定事实检查；缺少硬件序列号的问题未被补造答案。
10. 中译英、英译中、真实第 7 页翻译和 Markdown 导出。
11. 真实论文框架及 Mermaid 脚本生成。

## 修复及定向复测

- 问答改用 JSON 结构的结论和引用编号数组，逐个完整对象校验后推送 claim，待校验 token 预览只显示正文；伪造编号、无来源事实和不完整响应仍被拒绝。保留旧逐行协议的兼容解析，并接受分隔符两侧空格变化。
- 作者问题补取首页署名与机构区域，按几何行顺序排列，组合证据使用独立缓存键，避免与正文片段混用。真实问题返回第六作者 Aidan N. Gomez，署名机构 University of Toronto。
- OCR 合并段落时避免竖排水印吞并标题与正文；保留行坐标以估计醒目标题。解析后仅补写“未识别标题”，不覆盖手工标题。扫描样本 15 页重新解析约 145.2 秒，标题为 Attention Is All You Need。
- 图谱改为确定性力导向布局，编号节点配合悬停/键盘聚焦标题、相邻边突出、可搜索的全量文献索引；浏览器实测搜索 BERT 与出处弹窗。新截图：`screenshots/report-fixes-graph.jpg`。扫描件识别出题名后，该副本也能成为题名匹配目标，图谱为 39 个文件节点、261 条匹配边；仍包含重复版本，未逐条人工验准。
- 定向真实模型检查 **8/8 通过**：扫描件标题、普通 PDF GPU/Adam、第六作者及机构、扫描件 GPU/Adam、拒绝编造序列号、跨文来源覆盖、Agent 工具执行及综合回答、SSE token/claim/result 序列。SSE 本次为 27 个 token、3 个 claim、1 个 result，无 error。
- 最终隔离回归测试 **139 项通过，30.40 秒**；JavaScript 语法和 Python 编译检查通过。新增检查覆盖 JSON 任意分片、伪造/缺失来源、未完成 JSON、作者几何排序、OCR 水印隔离与保留手工标题。
