## 作品简介

研舟是面向科研论文阅读与材料整理的全栈应用，将 PDF 上传解析、内容与版本检查、原文证据问答、双语阅读、arXiv 检索追踪、引用图谱和写作绘图放在同一个工作台。系统保存原始文献、页码坐标和引用关系，支持从回答、参考条目和图谱边回到出处，并提供公式排版、原图对照与逐条修改保存。后端集成 MiMo 文本、工具和视觉接口，本地配置支持 BGE-M3 与 reranker，云端采用独立 Docker 轻量配置。

## 演示操作顺序

1. 登录后查看文献库数量、处理状态与不同版本。
2. 打开 Attention v7，查看目录、结构与原始页面。
3. 在问答中选择对应文献，询问训练 GPU 与 Adam 参数，点击出处。
4. 在阅读页打开公式排版，修改、保存并再次读取。
5. 查看译文、参考文献及正文引用的双向定位。
6. 以完整题名或 arXiv 编号检索目标论文，切换排序和检索范围。
7. 查看引用图谱、节点来源及综述入口。
8. 打开写作与绘图，使用随附示例 CSV 生成图表并导出。
